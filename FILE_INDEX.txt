KEY CONCEPTS CHEAT SHEET
================================================================================

STRATEGY DEVELOPMENT
├─ Create StrategyConfig class
├─ Create Strategy class inheriting from Strategy
├─ Implement on_start() - Subscribe to data
├─ Implement on_bar() - Main trading logic
├─ Implement on_stop() - Cleanup
└─ Same code works for backtest AND live trading

INDICATORS
├─ Use built-in: EMA, SMA, RSI, MACD, Bollinger Bands, etc.
├─ Register with: register_indicator_for_bars()
├─ Create custom: Subclass from Indicator base class
└─ Update manually: indicator.handle_bar(bar) if not auto-registered

DATA ACCESS
├─ Position: cache.position(instrument_id)
├─ Orders: cache.orders(instrument_id)
├─ Market Data: cache.bars(bar_type), cache.quote_ticks(), cache.trade_ticks()
├─ Account: cache.account(), cache.balance(venue)
└─ Always re-fetch from cache (don't store references)

ORDER EXECUTION
├─ Entry: self.buy(quantity) or self.sell(quantity)
├─ Exit: self.close_position(position_id)
├─ Modify: self.modify_order(order_id)
├─ Cancel: self.cancel_order(order_id)
└─ Path: Strategy → Message Bus → ExecEngine → Venue

POSITION MANAGEMENT
├─ Check: position.is_long, position.is_short, position.is_flat
├─ Access: position.quantity, position.entry_price, position.side
├─ Netting Mode: One position per instrument (default)
└─ Hedging Mode: Multiple positions allowed

ARCHITECTURE AT A GLANCE
================================================================================

Data Flow:
  Exchange/Venue → Data Client → Message Bus → 
  Cache, DataEngine, ExecutionEngine → Strategy

Strategy Components:
  StrategyConfig (parameters) + Strategy (logic) + Indicators (analysis)

Key Methods:
  on_start() → Subscribe to data, register indicators
  on_bar() → Main trading logic
  on_stop() → Cleanup and close positions

Order Flow:
  self.buy/sell() → Message Bus → OrderEmulator/ExecAlgo → 
  RiskEngine → ExecutionEngine → ExecutionClient → Venue

Position Access:
  position = cache.position(instrument_id)
  position.is_long, position.is_short, position.is_flat
  position.quantity, position.entry_price

Data Access:
  cache.bars(), cache.quote_ticks(), cache.trade_ticks()
  cache.orders(), cache.position(), cache.account()
